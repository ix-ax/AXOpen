Important

This component requires cyclic data updates, which are typically sourced from the I/O system. Before using the component, make sure you invoke the Run method. Additionally, it's crucial to ensure that the Run method is positioned within a call tree that operates cyclically. Failing to initiate the Run method or not guaranteeing its cyclic execution can lead to malfunctions and unpredictable component behavior. In extreme circumstances, this could cause erratic controller behavior, potentially leading to equipment damage.

Use

VAR PUBLIC
    Sequencer : AxoSequencer;
    Steps     : ARRAY[0..7] OF AXOpen.Core.AxoStep;
END_VAR

METHOD PRIVATE UseInSequencer

    Sequencer.Run(THIS);
    Sequencer.Open();
    Sequencer.SequenceMode := eAxoSequenceMode#RunOnce;

    IF(Steps[0].Execute(Sequencer, 'Configure and restore reader')) THEN
        ExampleReader.Config.InfoTime      := LTIME#2S;
        ExampleReader.Config.ErrorTime     := LTIME#5S;
        ExampleReader.Config.TaskTimeout   := LTIME#50S;
        ExampleReader.Config.StartAddress  := WORD#0;
        ExampleReader.Config.RfidCodeSize  := WORD#50;
        ExampleReader.Restore();
        Sequencer.MoveNext();
    END_IF;

    IF(Steps[1].Execute(Sequencer, 'Reset reader')) THEN
        IF(ExampleReader.ResetReader().IsDone()) THEN
            Sequencer.MoveNext();
        END_IF;
    END_IF;

    IF(Steps[2].Execute(Sequencer, 'Read tag data')) THEN
        IF(ExampleReader.Read().IsDone()) THEN
            Sequencer.MoveNext();
        END_IF;
    END_IF;

    IF(Steps[3].Execute(Sequencer, 'Write tag data')) THEN
        IF(ExampleReader.Write().IsDone()) THEN
            Sequencer.MoveNext();
        END_IF;
    END_IF;

    IF(Steps[4].Execute(Sequencer, 'Write single char to memory')) THEN
        IF(ExampleReader.WriteCharToMemory(character     := BYTE#16#41,  // 'A'
                                           Address       := WORD#0,
                                           NumberOfBytes := WORD#1
                                           ).IsDone()) THEN
            Sequencer.MoveNext();
        END_IF;
    END_IF;

    IF(Steps[5].Execute(Sequencer, 'Reset communication')) THEN
        IF(ExampleReader.ResetCommunication().IsDone()) THEN
            Sequencer.MoveNext();
        END_IF;
    END_IF;

    IF(Steps[6].Execute(Sequencer, 'Error recovery')) THEN
        ExampleReader.Restore();
        Sequencer.MoveNext();
    END_IF;

    IF(Steps[7].Execute(Sequencer, 'Complete')) THEN
        Sequencer.CompleteSequence();
    END_IF;
END_METHOD

Additional scenario — manual control

A second scenario demonstrates operating the reader from the HMI without a sequencer (all tasks are triggered from the RenderableContentControl command view). See Axo_BIS_M_4XX_045_ManualControl.st:

VAR PUBLIC
    ManualReader : AXOpen.Components.Balluff.Identification.Axo_BIS_M_4XX_045;
END_VAR

ManualReader.Config.InfoTime      := LTIME#2S;
ManualReader.Config.ErrorTime     := LTIME#5S;
ManualReader.Config.TaskTimeout   := LTIME#50S;
ManualReader.Config.StartAddress  := WORD#0;
ManualReader.Config.RfidCodeSize  := WORD#50;

ManualReader.Run(  inParent := THIS,
                   hwID     := AXOpen.Showcase.HwIdentifiers#BNIPNT507005Z040_HwID);

// This scenario has no sequencer -- the reader is operated entirely
// from the RenderableContentControl (Command-Control presentation):
//   * Restore             -- applies Config and clears errors
//   * Read                -- triggers ReadTask on the connected tag
//   * Write               -- triggers WriteTask with the configured payload
//   * ResetReader         -- restarts the reader firmware
//   * ResetCommunication  -- restarts the PROFINET communication channel
//   * WriteCharToMemory   -- writes a single byte at a configurable address

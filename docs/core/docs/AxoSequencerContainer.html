AxoSequencerContainer

AxoSequencerContainer extends AxoSequencer and is the preferred way to implement sequences in AXOpen applications. Unlike AxoSequencer which requires explicit Open() calls, AxoSequencerContainer is self-managing — you extend it, override Main, and place all step logic there.

Key differences from AxoSequencer

Aspect AxoSequencer AxoSequencerContainer
Instantiation Direct Abstract — must extend
Open() call Manual (required) Automatic (handled by Run())
Logic location Inline in calling code Encapsulated in Main override
Reusability Single-use Reusable class pattern

When to use

Use AxoSequencerContainer for production sequences (Automat, Ground, Service modes). Use AxoSequencer for simple inline demos or one-off sequences.

SequenceMode — RunOnce with localizable descriptions

The following example demonstrates eAxoSequenceMode#RunOnce mode with localizable step descriptions and RequestStep for conditional branching back to a previous step:

{S7.extern=ReadWrite}
CLASS AxoSequencerContainerRunOnceExample EXTENDS AXOpen.Core.AxoSequencerContainer
    VAR PUBLIC
        _restoreStep : AxoStep;
        _processStep : AxoStep;
        _checkStep : AxoStep;
        _finalStep : AxoStep;
        _myCounter : ULINT;
        _checkPassed : BOOL;
    END_VAR

    METHOD PROTECTED OVERRIDE Main
        // RunOnce mode: sequence executes once and stays Done
        THIS.SequenceMode := eAxoSequenceMode#RunOnce;

        _myCounter := _myCounter + ULINT#1;

        IF(_restoreStep.Execute(THIS, TRUE, '<#RESTORE STATE#>')) THEN
            _myCounter := ULINT#0;
            _checkPassed := FALSE;
            THIS.MoveNext();
        END_IF;

        IF(_processStep.Execute(THIS, TRUE, '<#PROCESS DATA#>')) THEN
            IF(_myCounter >= ULINT#100) THEN
                _myCounter := ULINT#0;
                THIS.MoveNext();
            END_IF;
        END_IF;

        IF(_checkStep.Execute(THIS, TRUE, '<#CHECK RESULT#>')) THEN
            IF(_myCounter >= ULINT#50) THEN
                _myCounter := ULINT#0;
                IF _checkPassed THEN
                    THIS.MoveNext();
                ELSE
                    // Branch back to process step on failure
                    THIS.RequestStep(_processStep);
                END_IF;
            END_IF;
        END_IF;

        IF(_finalStep.Execute(THIS, TRUE, '<#FINALIZE#>')) THEN
            THIS.CompleteSequence();
        END_IF;
    END_METHOD
END_CLASS

Branching with RequestStep

Use RequestStep to branch to different steps based on runtime conditions. When the target step is declared after the current one, it executes in the same cycle; when before, in the next cycle:

{S7.extern=ReadWrite}
CLASS AxoSequencerContainerBranchingExample EXTENDS AXOpen.Core.AxoSequencerContainer
    VAR PUBLIC
        _initStep : AxoStep;
        _evaluateStep : AxoStep;
        _pathAStep : AxoStep;
        _pathBStep : AxoStep;
        _doneStep : AxoStep;
        _condition : BOOL;
        _myCounter : ULINT;
    END_VAR

    METHOD PROTECTED OVERRIDE Main
        THIS.SequenceMode := eAxoSequenceMode#Cyclic;

        _myCounter := _myCounter + ULINT#1;

        IF(_initStep.Execute(THIS, TRUE, '<#INITIALIZE#>')) THEN
            _myCounter := ULINT#0;
            THIS.MoveNext();
        END_IF;

        IF(_evaluateStep.Execute(THIS, TRUE, '<#EVALUATE CONDITION#>')) THEN
            // Branch to different steps based on condition
            IF _condition THEN
                THIS.RequestStep(_pathAStep);
            ELSE
                THIS.RequestStep(_pathBStep);
            END_IF;
        END_IF;

        IF(_pathAStep.Execute(THIS, TRUE, '<#PATH A - CONDITION MET#>')) THEN
            IF(_myCounter >= ULINT#100) THEN
                _myCounter := ULINT#0;
                THIS.RequestStep(_doneStep);
            END_IF;
        END_IF;

        IF(_pathBStep.Execute(THIS, TRUE, '<#PATH B - CONDITION NOT MET#>')) THEN
            IF(_myCounter >= ULINT#100) THEN
                _myCounter := ULINT#0;
                THIS.RequestStep(_doneStep);
            END_IF;
        END_IF;

        IF(_doneStep.Execute(THIS, TRUE, '<#COMPLETE#>')) THEN
            THIS.CompleteSequence();
        END_IF;
    END_METHOD
END_CLASS

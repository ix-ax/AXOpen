This method commands the axis to perform the «search home» sequence. The details of this sequence aremanufacturer dependent and can be set by the axis’ parameters. The ‘Position’ input is used to set the absoluteposition when reference signal is detected. This method completes at ‘Standstill’ if it was started in ‘Standstill’.

# AXOpen.Components.Abstractions

This documentation contains information about `AXOpen.Components.Abstractions` library.

[!INCLUDE [General](../../../docfx/articles/notes/LIBRARYHEADER.md)]

## Description

The **components.abstractions** library contains interfaces and abstract classes that are used as foundation for other component libraries in the [AxOpen](https://github.com/inxton/AXOpen?tab=readme-ov-file) framework.

The package consists of a PLC library providing base abstractions and its .NET twin counterpart.

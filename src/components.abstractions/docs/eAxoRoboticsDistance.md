# eAxoRoboticsDistance

_Distance-axis selector for robotics distance helpers._

## Description

`eAxoRoboticsDistance` (namespace `AXOpen.Components.Abstractions.Robotics`) enumerates the axis combinations over which a distance / displacement may be evaluated.

| Value | Axes |
|-------|------|
| `X` | X only |
| `Y` | Y only |
| `Z` | Z only |
| `XY` | X and Y |
| `XZ` | X and Z |
| `YZ` | Y and Z |
| `XYZ` | X, Y and Z (full 3D distance) |

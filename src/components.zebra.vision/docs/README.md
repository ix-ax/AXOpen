# AXOpen.Components.Zebra.Vision

This documentation contains information about `AXOpen.Components.Zebra.Vision` library.

[!INCLUDE [General](../../../docfx/articles/notes/LIBRARYHEADER.md)]

## Description

The **components.zebra.vision** is a library covering fixed industrial scanners and machine vision systems from the vendor [Zebra Technologies](https://www.zebra.com/) for the target PLC platform [Siemens AX](https://www.siemens.com/global/en/products/automation/industry-software/automation-software/simatic-ax.html) and [AxOpen](https://github.com/inxton/AXOpen?tab=readme-ov-file) framework.

The package consists of a PLC library providing control logic and its .NET twin counterpart aimed at the visualization part.

### For proper function, make sure you have included these files:

## 1. Bootstrap CSS

In your `_Host.cshtml` file, include the bootstrap css:

```html
<link rel="stylesheet" href="~/css/bootstrap/bootstrap.min.css" />
```

## 2. Bootstrap JS

In your `_Host.cshtml` file, on the end include the bootstrap js:

```html
<script src="~/js/bootstrap.bundle.min.js"></script>
```
